# WeatherTripPlanner

**WeatherTripPlanner** — это современное Android-приложение для планирования путешествий, которое позволяет пользователям составлять список поездок и получать актуальные данные о погоде в пункте назначения.

## Основные возможности

*   **Планирование поездок**: Добавление новых маршрутов с указанием названия, города и даты.
*   **Список путешествий**: Удобный просмотр всех запланированных поездок на главном экране.
*   **Интеграция с погодой**: Получение текущих метеоусловий (температура, влажность, состояние неба) для выбранного города в реальном времени.
*   **Детализация**: Просмотр подробной информации о каждой конкретной поездке.
*   **Удаление данных**: Возможность быстрой очистки списка от неактуальных планов.
*   **Offline-режим**: Благодаря локальной базе данных, информация о поездках доступна даже без интернет-соединения.

## Технологический стек

Приложение разработано с использованием актуальных практик Android-разработки:

*   **UI**: Jetpack Compose (декларативный интерфейс).
*   **Архитектура**: MVVM (Model-View-ViewModel) для четкого разделения логики и отображения.
*   **База данных**: Room Persistence Library для локального хранения данных.
*   **Сеть**: Retrofit + GSON для взаимодействия с API OpenWeather.
*   **Навигация**: Navigation Compose для переходов между экранами.
*   **Загрузка изображений**: Coil для отображения иконок погоды.
*   **Аналитика**: Firebase Analytics для мониторинга использования приложения.

## Структура проекта

*   `com.example.weathertripplanner`
    *   `data/`: Сущности БД (`TripEntity`), DAO и конфигурация Room (`AppDatabase`).
    *   `network/`: Сетевые интерфейсы API и модели ответов (DTO).
    *   `ui/`: Компоненты интерфейса, разделенные на:
        *   `navigation/`: Настройка маршрутов и графа навигации.
        *   `screens/`: Основные экраны приложения (`Trips`, `AddTrip`, `TripDetails`, `Weather`).
        *   `theme/`: Определение стилей, цветов и типографики (Material 3).
    *   `viewmodel/`: `TripViewModel` — центральный узел управления состоянием приложения.

## Настройка

1.  **API Ключ**: Для работы погодного сервиса требуется API-ключ от OpenWeatherMap. Он должен быть прописан в конфигурационных файлах проекта.
2.  **Google Services**: Для корректной работы сервисов Firebase необходимо наличие файла `google-services.json` в директории `app/`.
3.  **Сборка**: Проект собирается с помощью Gradle (Kotlin DSL). Минимальная поддерживаемая версия Android — 7.0 (API 24).

## Разработка

Приложение использует современную библиотеку Material 3 для дизайна и Room для реактивного обновления данных (через Kotlin Flow). Все запросы к сети выполняются асинхронно с использованием корутин.
